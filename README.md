# Lingora — site institucional

Site estático, responsivo e em português, construído a partir das duas imagens fornecidas.

## Como visualizar
Abra `index.html` no navegador. Para publicar, envie a pasta inteira para uma hospedagem de site estático (por exemplo, GitHub Pages, Netlify ou Vercel).

## Configurar o WhatsApp
1. Abra `script.js`.
2. Na primeira linha de configuração, substitua `""` pelo número completo, com código do país e DDD.
3. Use apenas números. Exemplo de formato: `5562999999999`.
4. Salve e publique novamente.

## Personalização
- Textos e seções: `index.html`
- Cores, tipografia e layout: `styles.css`
- Menu e botão de contato: `script.js`
- Imagens originais: `assets/`

## Observação
O formulário/contato não envia dados para um servidor. O botão de contato abre uma conversa no WhatsApp depois que o número real for configurado em `script.js`.
